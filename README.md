# Amzon_polly_text_to_speech
# 🔊 Amazon Polly Text-to-Speech Application  This project demonstrates how to use AWS Polly to convert text into realistic, human-like speech. It supports multiple voices, languages, and audio formats, making it useful for accessibility, AI assistants, and automation systems.
## 🚀 Features
- Convert text to speech using Amazon Polly
- Supports multiple languages and voices
## 🛠️ Technologies Used
- Python
- AWS SDK (Boto3)
- Amazon Polly
